# 配置WsToken<Badge type="warning" text="普通" />

<Callout type="warn" title="">

`config.json`文件位于`gsuid_core/data/config.json`

如GsCore和连接端Bot(如NoneBot2)都位于本机, 则无需配置WsToken

(同时部署于Docker容器中时, 也需要配置WsToken)

否则, 请配置WsToken或者TrustIP以确保安全, [配置说明](../started/core-config)

</Callout>

<Callout type="info" title="">

连接端处Token和GsCore处的WsToken需要**保持一致**！

</Callout>

## 1. 配置GsCore处的WsToken

- 通过网页控制台修改`WS_TOKEN`或`TRUSTED_IPS`
- 通过修改`config.json`文件, 找到`WS_TOKEN`或`TRUSTED_IPS`字段, 进行修改

## 2. 配置连接端处的WsToken

### 1. NoneBot2

- 修改`.env`文件, 新建`gsuid_core_ws_token`字段, 填写GsCore处的WsToken
    - `gsuid_core_ws_token=123`

### 2. HoshinoBot

- 修改`client.py`文件, 找到17行的`WS_TOKEN`字段, 填写GsCore处的WsToken

### 3. AstrBot

- 直接通过WebUI修改配置文件，找到`WS_TOKEN`字段, 填写GsCore处的WsToken

### 4. 其他Bot

- 如有提供其他Bot的适配器, 请参考适配器的配置说明, 填写GsCore处的WsToken
- GsCore侧的连接URL为: `ws://``HOST``:``PORT``/``BOT_ID``?token=``WS_TOKEN```
- 该接口有限流处理, 如有其他适配器编写, 还需要注意
