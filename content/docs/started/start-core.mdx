# 启动Core<Badge type="tip" text="简单" />

<Callout type="warn">
下面四种启动方式，根据你安装时使用的工具选择即可。

启动时需移动至主路径, 例如`E:\gsuid_core`

示例命令 `cd E:\MyPyProject\gsuid_core`

:::
## 启动命令

<details><summary>【🥳 推荐】UV启动</summary>

```sh
uv run core
```

:::
<details><summary>Poetry启动</summary>

```sh
poetry run core
```

:::
<details><summary>PDM启动</summary>

```sh
pdm run core
```

:::
<details><summary>【😡 不推荐】直接使用Python</summary>

```sh
# 不推荐使用该方法
python -m gsuid_core.core
```

:::
