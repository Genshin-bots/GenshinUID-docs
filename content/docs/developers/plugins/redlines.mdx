## 绝对避免

| 红线 | 原因 |
|------|------|
| 大面积 `try/except: pass` 吞错 | 线上静默坏掉，极难查 |
| 对同一函数同时 `to_ai` 与 `@ai_tools` | 重复注册 / 行为异常 |
| 在触发器里同步阻塞（重 CPU、同步 HTTP） | 卡死整个 Core 事件循环 |
| 主动推送硬编码群号循环 `target_send` | 应用 `gs_subscribe` |
| 触发器里使用 `_Bot` | 只用高层 `Bot` |
| `cast` / `type: ignore` / `getattr` 乱兜底 | 掩盖类型与数据错误 |

## 少数例外

- **`ai_return` 辅助函数**内允许 try/except，失败只打日志，不影响出图  
- 与第三方 API 边界：捕获后**明确** `bot.send` 错误原因，不要空 except  

## 性能

```python
# 重计算
import asyncio
await asyncio.to_thread(cpu_bound_fn, ...)
```

## 安全

- 管理命令设好 `pm`  
- 危险操作不要 `to_ai`  
- 密钥走配置，不进 git
