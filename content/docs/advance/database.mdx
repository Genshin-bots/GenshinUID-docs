# 配置数据库<Badge type="tip" text="稍难" />

### 支持

- SQLite
- MySQL（包含MariaDB）
- ~~PostgreSQL~~（暂不支持）

### 默认情况

默认会使用*SQLite*作为数据库，无需用户配置。

### 使用MySQL

<Callout type="warn" title="">

该方法仅限高阶用户使用, 不建议小白用户使用！

该功能仍处于实验性。

</Callout>

[commit](https://github.com/Genshin-bots/gsuid_core/commit/ef151d55d350e2311a2b88cebb0b31cd8fea7a7c#diff-f350e4e9a29e6934e1112ec3b861637c29f49492d637484f0492f11aa270ccce)

1. 安装MySQL，并启动服务
2. 前往[网页控制台](../started/web-console)
3. 【侧边栏】->【插件管理】->【修改插件设定】->【GsCore数据库配置】
4. 进行配置
   1. 【数据库类型】清空, 选择MySQL
   2. 【MySQL驱动】选择喜欢的即可（根据选择的不同需要安装不同的依赖）
      1. `uv run python -m pip install aiomysql -U`
      2. `uv run python -m pip install asyncmy -U`
   3. 【数据库地址】、【数据库端口】、【数据库用户名】、【数据库密码】按照安装MySQL的情况如实填写
   4. 其他按照情况填写，点击确认修改
5. 重启GsCore
