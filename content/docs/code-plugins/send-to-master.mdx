# 发送消息至主人<Badge type="tip" text="简单" />

[参考](https://github.com/Genshin-bots/gsuid_core/commit/02e8640bd41f49dcee65b88b70701479e5c137d6)

```python
from gsuid_core.aps import scheduler
from gsuid_core.utils.message import send_msg_to_master

@scheduler.scheduled_job('cron', hour=6, minute=7)
async def update_core_at_night():
    await send_msg_to_master('发送这条消息')
```
