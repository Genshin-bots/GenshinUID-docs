## 开始前：目录放哪？

没有强制路径，但建议和 Bot 放在同级，方便以后找：

```
D:\Bots\                 # 举例：Windows
├── nonebot2\            # 你的上游 Bot（稍后装）
└── gsuid_core\          # 本教程要克隆的 Core
```

Linux / macOS 同理，如 `~/bots/gsuid_core`。

<BeginnerTip title="路径里尽量别有奇怪字符">

新手建议用纯英文路径，避免空格和中文目录导致个别脚本翻车（不是绝对不行，但排错更难）。

</BeginnerTip>

### 装依赖失败？

| 现象 | 处理 |
|------|------|
| 下载超时 / 很慢 | 换国内 PyPI 镜像，或开系统代理 |
| `greenlet DLL load failed`（Windows） | `uv pip install greenlet msvc-runtime` |
| 权限错误 | 不要用错系统 Python；确保在项目 venv 里 |

### 第一次启动会发生什么？

1. 创建 `data/` 目录  
2. 生成 `data/config.json`（含随机 **REGISTER_CODE**）  
3. 初始化 SQLite：`data/GsData.db`  
4. 加载 `plugins/`（若还没有业务插件，插件数可能很少）  
5. 启动 WebSocket + 网页控制台  

### 怎样算启动成功？

日志里大致会出现：

```
🌱 [早柚核心] 已启动!
🚀 [GsCore] 启动完成, 耗时: x.xxs, 版本: ...
📦 插件: … | 🛠️ 服务: … | ⚡ 触发器: …
```

以及表示 WS 服务已起来的相关输出。

浏览器先试：`http://localhost:8765/app`  
若能打开登录/注册页，说明 HTTP 侧正常（下一步用注册码登录见 [网页控制台](./webconsole/)）。

### 临时改端口 / 监听地址（不写配置文件）

```shell
uv run core --host 0.0.0.0 --port 9527
uv run core --dev
```

命令行参数**优先级高于**配置文件，且**不会自动写回** `config.json`。

## 可选：先手动塞一颗插件

Core 几乎是「空壳」。你可以：

**A.** 下一章配好主人后，在聊天里发 `core安装插件GenshinUID`（更方便）  
**B.** 现在就手动 clone：

```shell
cd gsuid_core/plugins
git clone -b v4 https://github.com/KimigaiiWuyi/GenshinUID.git --depth=1 --single-branch
cd ../../
# 重启 Core 后加载
```

## 后台长期运行（了解即可）

| 系统 | 常见做法 |
|------|----------|
| Linux 服务器 | systemd / supervisor，`Restart=always` |
| Windows | [NSSM](https://nssm.cc/) 把 `uv run core` 注册为服务 |
| Docker | 见 [Docker](./docker/) 的 `--restart always` |

日常开发可以一直用前台 `uv run core`，改代码后重启即可。

聊天内（主人权限）：`core重启` 会尝试拉起新进程；`gs关闭Core` 直接退出（靠外部守护进程拉起）。

## 启动失败对照表

| 日志 / 现象 | 你该检查 |
|-------------|----------|
| `ModuleNotFoundError: gsuid_core` | 是否在仓库根目录执行 |
| `Address already in use` | 8765 被占用 → 换 `--port` 或改配置 |
| 窗口闪退 | 用终端启动看完整报错；查 `data/logs/` |
| 启动成功但 `/app` 打不开 | 防火墙 / 是否监听 localhost / 端口是否映射 |
| Bot 还连不上 | **正常**：还没做 [首次配置](./first-config/) 和 [链接 Bot](./link-bot/) |

## 成功后你已经拥有什么？

- 本机可运行的 Core 进程  
- `data/config.json`（**请先别删**，里面有注册码）  
- 可访问的 WebConsole 入口  

还没有：主人权限配置、与 QQ 等平台的连接、好玩的业务命令——继续往下。
