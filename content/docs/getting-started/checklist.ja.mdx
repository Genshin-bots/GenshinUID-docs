## 基盤

- [ ] Core が安定起動する  
- [ ] `masters` に自分の ID  
- [ ] 公開時は `HOST=0.0.0.0` と `WS_TOKEN`  
- [ ] `http://HOST:PORT/app` でログイン可能  

## 接続

- [ ] Bot が Core に接続済み  
- [ ] メッセージが Core ログに出る  
- [ ] master で `core` 管理コマンドが使える  

## プラグイン

- [ ] 業務プラグインを 1 つ以上入れ再起動済み  
- [ ] コマンドが応答する
