## One-line model

| Piece | Think of it as… |
|------|------------------|
| **Core** | The **brain** (commands, plugins, DB, optional AI) |
| **Bot** | The **mouth & ears** (talks to QQ / Telegram / …) |
| **Adapter** | The **translator** (platform protocol ⇄ GsCore) |
| **Plugin** | A **skill cartridge** (UID query, art, push jobs) |

<BeginnerTip title="The one sentence that matters">

**Core is not a full chatbot.** You must connect an upstream Bot (+ adapter). Starting Core alone never delivers group messages.

</BeginnerTip>

## Where data lives

| Path | Meaning |
|------|---------|
| `data/config.json` | masters, port, WS token, register code |
| `data/` | Runtime “save data” |
| `gsuid_core/plugins/` | Plugin **code** |
