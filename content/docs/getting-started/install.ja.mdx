**ソース導入**の手順です。コンテナは [Docker](./docker/) へ。

## クローン

```shell
git clone https://github.com/Genshin-bots/gsuid_core.git --depth=1 --single-branch
# ミラー: https://cnb.cool/gscore-mirror/gsuid_core.git
cd gsuid_core
```

## 依存関係

リポジトリ直下（`pyproject.toml` がある場所）で実行。

## 起動

```shell
uv run core
uv run core --host 0.0.0.0 --port 9527
```

初回起動で `data/` と `REGISTER_CODE` 付き `config.json` が作成されます。
