## 1. Python 版本

GsCore 需要：

| | 要求 |
|--|------|
| **最低** | Python **3.11** |
| **推荐** | **3.12**（Docker 官方镜像也是 3.12） |
| **不建议** | 3.14 及以上（部分依赖可能还没有 wheel） |

<CheckItem
  step={1}
  title="检查 Python 是否已安装"
  subtitle="期望输出类似 Python 3.12.x"
  badge={{ text: "必做", type: "warning" }}
  storageKey="gs-env-python"
>

```shell
python -V
```

如果提示找不到命令，再试：

```shell
python3 -V
# Windows 有时是：
py -3.12 -V
```

### 还没有 Python？按系统安装

<OsTabs label="选你的系统看安装方式">

<div data-os="windows">

1. 打开 [python.org Windows 下载页](https://www.python.org/downloads/windows/)  
2. 下载 **3.12.x** 安装包  
3. 安装时**务必勾选**底部 **「Add python.exe to PATH」**  
4. **关掉并重新打开** PowerShell，再执行 `python -V`

<Callout type="warn" title="">

没勾选 PATH 是新手最常见翻车点：装完了终端仍提示找不到 `python`。

</Callout>

</div>

<div data-os="linux">

Debian / Ubuntu 示例：

```shell
sudo apt update
sudo apt install -y python3.12 python3.12-venv python3-pip
python3.12 -V
```

若仓库没有 3.12，可用系统自带的 `python3`，只要版本 ≥ 3.11。

</div>

<div data-os="macos">

推荐用 Homebrew：

```shell
brew install python@3.12
python3.12 -V
```

</div>

</OsTabs>

<BeginnerTip variant="why" title="为什么卡版本？">

Core 的 `pyproject.toml` 写明了 `requires-python >=3.11,<4.0`。版本过旧会装不上依赖；过新则某些编译包可能失败。

</BeginnerTip>

</CheckItem>

## 2. Git

装插件、克隆仓库、自动更新都依赖 Git。

<CheckItem
  step={2}
  title="检查 Git"
  subtitle="版本 ≥ 2.0 即可"
  badge={{ text: "必做", type: "warning" }}
  storageKey="gs-env-git"
>

```shell
git -v
# 有的环境是 git --version
```

期望类似：`git version 2.42.0.windows.1`

### 未安装时

<OsTabs>

<div data-os="windows">

前往 [git-scm.com](https://git-scm.com/) 下载安装包。  
安装向导可一路默认；装完**重开终端**再测 `git -v`。

</div>

<div data-os="linux">

```shell
sudo apt install -y git
```

</div>

<div data-os="macos">

```shell
brew install git
# 或安装 Xcode Command Line Tools：
# xcode-select --install
```

</div>

</OsTabs>

</CheckItem>

## 4. 端口与资源（轻量检查）

Core 默认占用 **8765** 端口（可在配置里改）。

<CheckItem
  step={4}
  title="确认 8765 端口空闲（或准备改端口）"
  subtitle="被占用时后面启动会 Address already in use"
  badge={{ text: "建议", type: "info" }}
  storageKey="gs-env-port"
>

<OsTabs>

<div data-os="windows">

```shell
netstat -ano | findstr 8765
```

没有输出 = 端口空闲。有输出则记下 PID，或准备在配置里改 `PORT`。

</div>

<div data-os="linux">

```shell
ss -lptn 'sport = :8765'
# 或
lsof -i:8765
```

</div>

<div data-os="macos">

```shell
lsof -i:8765
```

</div>

</OsTabs>

### 机器资源参考

| 资源 | 最低 | 推荐 |
|------|------|------|
| 内存 | 1 GB | 2 GB+（开 AI 嵌入 / Rerank 更吃） |
| 磁盘 | 2 GB | 10 GB+（资源图、日志、备份） |
| 网络 | 能访问外网 | 国内可准备镜像 / 代理 |

</CheckItem>

## 可选：Playwright 浏览器

部分插件用浏览器渲染图片。源码首次启动可能自动下载 Chromium（约 130MB）。  
**Docker 镜像已预装**，可跳过。

```shell
uv run playwright install chromium
# 下载慢时可设国内镜像环境变量后再装：
# set PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/
```
