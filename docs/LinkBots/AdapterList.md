# 适配早柚核心的Bot<Badge type="tip" text="简单" />

::: tip

感谢适配编写者（们），你可以选择以下任意Bot进行链接。

适配以下Bot，安装以下bot的对应连接器，然后启动早柚核心（gsuid_core）即可使用

:::

### 🤖 NoneBot2 [推荐]

[机器人](https://github.com/nonebot/nonebot2) | [适配器](https://github.com/KimigaiiWuyi/GenshinUID/tree/v4-nonebot2)

✨ 跨平台 Python 异步聊天机器人框架 / Asynchronous multi-platform chatbot framework written in Python

✨ 支持OneBot(QQ)、OneBotV12、RedProtocol（NTQQ）、QQ频道、微信（NtChat）、KOOK（开黑啦）、Telegram（电报）、FeiShu（飞书）、DoDo（渡渡）、Villa（米游社大别野）、Discord等


### 🤖 HoshinoBot

[机器人](https://github.com/Ice9Coffee/HoshinoBot) | [适配器](https://github.com/KimigaiiWuyi/GenshinUID/tree/v4-hoshino)

✨ 一个基于Nonebot1的QQ机器人! 支持OneBot通用协议！

### 🤖 ZeroBot

[机器人](https://github.com/wdvxdr1123/ZeroBot) | [适配器](https://github.com/RemKeeper/GSUID_Utils_ZeroBot)

✨ 一个基于onebot协议的机器人Go开发框架，支持OneBot协议（QQ）！

### 🤖 YunZai-Bot

[机器人](https://github.com/yoimiya-kokomi/Miao-Yunzai) | [适配器](https://gitee.com/xiaoye12123/ws-plugin)

✨ 支持QQ协议登录！

### 🤖 Koishi

[机器人](https://github.com/koishijs/koishi) | [适配器](https://github.com/GithubCin/gscore-adpater)

✨ 用爱打造的跨平台聊天机器人框架! 支持Satori、OneBot通用协议以及各类平台！

### 🤖 XYBotV2

[机器人](https://github.com/HenryXiaoYang/XYBotV2) | [适配器](https://github.com/qiye531667706/XYBotV2-GsCoreAdapter)

✨ 功能丰富的微信机器人框架 | AI对话、对接Dify、积分系统、游戏互动、每日新闻、天气查询 | 非Hook非Web实现 | 支持 Windows✅ Linux✅ MacOS✅ | 全新架构解决XYBot第一代痛点！

### 🤖 AstrBot

[机器人](https://github.com/Soulter/AstrBot) | [适配器](https://github.com/KimigaiiWuyi/astrbot_plugin_gscore_adapter)

✨ 易上手的多平台 LLM 聊天机器人及开发框架 ✨ 平台支持 QQ、QQ频道、Telegram、微信、企微、飞书 | MCP 服务器、OpenAI、DeepSeek、Gemini、硅基流动、月之暗面、Ollama、OneAPI、Dify 等。附带 WebUI。

## 独立连接器

[Java] [gs-core-adapter](https://gitee.com/WeekDragon/gs-core-adapter) - 该适配器连接RedProtocol协议和GsCore

[TypeScript] [napcat-plugin-gscore-adapter](https://github.com/xiowo/napcat-plugin-gscore-adapter) - 直接使用NapCat连接GsCore
