确认环境有无缺失简单 ​

阅读时长:1 分钟
  • 确保安装Python环境（版本须>=3.7， 建议>=3.10，不建议>=3.12）
  • 部分插件不支持3.10以下的python版本（例如StarrailUID），GenshinUID支持3.7版本

# 命令行内输入
python -V

>>> Python 3.x.x
